Together — Demander la suppression de vos données

Arcail² Studio vous permet de demander la suppression de votre compte de jeu (identifiant de joueur Unity), de sa sauvegarde cloud et de vos scores au classement.

Comment envoyer une demande

  1. Dans Together, ouvrez Réglages → Confidentialité → Demander la suppression de mes données. L’identifiant de votre partie est alors prérempli ci-dessous.
  2. Utilisez le bouton pour préparer un courriel à arcail2studio.contact@gmail.com, puis envoyez-le depuis votre messagerie. Vous pouvez aussi écrire directement à cette adresse si vous n’avez plus accès au jeu.
  3. Le studio pourra vous demander des informations limitées pour vérifier que la partie vous appartient. N’envoyez jamais de mot de passe, de code de connexion ou de coordonnées bancaires.

Ouvrir cette page ne supprime rien et n’envoie aucune demande automatiquement. Nous répondons dans les délais légaux applicables et confirmons le traitement de la demande.

Identifiant de votre partie

Ce champ reste dans votre navigateur. Il n’est inclus que dans le courriel que vous choisissez d’envoyer. Laissez-le vide si vous ne le connaissez pas.

Ce qui est supprimé et ce qui peut être conservé

La demande concerne l’identifiant de joueur Unity Authentication associé à Together et sa sauvegarde Unity Cloud Save. Une éventuelle liaison Google Play Games est retirée avec ce compte de jeu. La suppression cloud est irréversible ; pendant le traitement, évitez d’ouvrir le jeu pour qu’il ne recrée pas de sauvegarde.

Si la sauvegarde cloud n’était pas activée dans votre version du jeu, votre progression n’existe que sur votre appareil.

Pour effacer les données enregistrées sur votre appareil, effacez les données de l’application dans les paramètres Android ou désinstallez-la. La preuve du traitement de votre demande peut être conservée pendant la durée imposée par la réglementation. Pour les données publicitaires traitées par Google, consultez les outils de confidentialité Google.

Together — Request deletion of your data

Arcail² Studio lets you request deletion of your game account (Unity player identifier), its cloud save and your ranking scores.

How to send a request

  1. In Together, open Settings → Privacy → Request data deletion. Your game identifier is then filled in above.
  2. Use the button to prepare an email to arcail2studio.contact@gmail.com, then send it from your mail app. You can also write to this address directly if you no longer have access to the game.
  3. The studio may ask for limited information to check that the game belongs to you. Never send a password, sign-in code or payment details.

Opening this page deletes nothing and sends no request automatically. We answer within the applicable legal time limits and confirm when the request has been handled.

Prepare my request by email

What is deleted and what may be kept

The request covers the Unity Authentication player identifier associated with Together and its Unity Cloud Save data. Any Google Play Games link is removed with this game account. Cloud deletion cannot be undone; while it is processed, avoid opening the game so that it does not create a new save.

If cloud saving was not enabled in your version of the game, your progression only exists on your device.

To erase the data stored on your device, clear the app’s data in Android settings or uninstall it. Proof that your request was handled may be kept for the period required by law. For advertising data processed by Google, see Google’s privacy tools.
